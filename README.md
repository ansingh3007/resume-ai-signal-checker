# resume-ai-signal-checker

A small command-line tool that checks a `.docx` resume for the signals that
AI-detector heuristics and ATS plugins actually key on — plus a check
against Harvard FAS's published resume-writing guidance.

There's no hidden "watermark" in AI-generated text for this tool to strip.
What it actually looks for is:

1. **Document metadata** — leftover tool fingerprints in `docProps/core.xml`
   / `docProps/app.xml` (e.g. "Generated by ChatGPT", suspicious app names,
   stray `customXml/` parts some AI writing tools inject).
2. **AI-cliché phrasing** — a curated list of stock LLM-isms ("leverage",
   "seamless", "spearheaded", "in today's fast-paced environment", etc.).
3. **Low "burstiness"** — human writing varies sentence length a lot; very
   uniform AI output often doesn't. Flags low coefficient-of-variation.
4. **Repetitive bullet openers** — the same verb opening 3+ bullets.
5. **Harvard FAS resume-guide checks** — no personal pronouns (Harvard's
   explicit "don't use I or We" rule), and every bullet opens with a verb
   from [Harvard's action-verb bank](https://careerservices.fas.harvard.edu/resources/create-a-strong-resume/).

## Usage

```bash
# Report findings (read-only, no files written)
python3 resume_clean.py inspect resume.docx

# Strip document metadata fingerprints -> writes a new file
python3 resume_clean.py clean resume.docx -o resume.cleaned.docx

# Also works on plain text/markdown (metadata checks are skipped)
python3 resume_clean.py inspect resume.txt
```

## Requirements

Python 3.9+, standard library only — no `pip install` needed.

## Notes

- This is heuristic, not a certified AI-detector result. It's meant to
  catch the same easy tells a human reviewer or basic ATS plugin would
  catch, not to make any claim about "AI-generated" in a legal or
  academic-integrity sense.
- `inspect` never modifies your file. Only `clean` writes output, and it
  only touches metadata, never the resume text itself.
- Bullet-opener and pronoun checks are tuned for a "**Bold Label:**
  sentence" bullet style. If your resume doesn't use bold labels before
  each bullet, those two checks fall back to checking the whole line.
